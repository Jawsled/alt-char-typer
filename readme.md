# Alt-Char Typer

A tiny PyQt6 desktop app with big buttons for characters that are alternatives to
ones Windows won't allow in file/folder names. Click a button and the character is
copied to your clipboard.

Including: `꞉` `／` `＼` `＊` `？` `＜` `＞` `｜`


*Are you tired of seeing this? yea me too.*
![alt](https://raw.githubusercontent.com/Jawsled/alt-char-typer/refs/heads/main/A%20file%20name%20cant%20contain%20any%20of%20the%20following%20characters.png)

## Requirements

- Python 3.9+
- PyQt6

```
pip install PyQt6
```

## Run

```
python alt_path_chars.py
```

Click any character to copy it.
